## Omen.toml

Status: 0.8 design/in progress.

The planned Omen.toml may describe project identity, known services, named checks, semantic operations, adapter configuration, important resources and named compositions.

It must not become policy, grant itself authority, replace ecosystem manifests, execute merely because it was read, redefine built-in capability semantics, or claim stronger assurance than Omen can prove.

The accepted schema will be documented/generated here when composition lands.
