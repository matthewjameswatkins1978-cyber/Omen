# 21. Notes and sources

The Omen Book is primarily documentation of Omen itself, but its documentation structure and shell-history introduction draw on established documentation.

## Shell history and model

GNU Bash Reference Manual:

https://www.gnu.org/software/bash/manual/

Its introduction begins with "What is Bash?" and "What is a shell?" and describes the Unix shell as both command interpreter and programming language.

## Rust documentation structure

The Rust Programming Language:

https://doc.rust-lang.org/book/

The Rust Reference:

https://doc.rust-lang.org/reference/

Rust demonstrates the value of separating a readable teaching book from a precise reference and shipping documentation for offline use.

## Fish

https://fishshell.com/docs/current/

Fish separates tutorial, interactive use and language reference.

## Nushell

https://www.nushell.sh/book/

Nushell separates getting started, fundamentals, programming, shell usage, migration guidance and design material.

## PowerShell

https://learn.microsoft.com/powershell/

PowerShell's conceptual documentation demonstrates the value of standalone searchable concept topics.
