# 16. Coming from other shells

Omen preserves useful shell habits rather than demanding that you forget everything you know.

## Bash or Zsh

Keep ordinary executable syntax, direct command-line work, pipelines and text tools where they are the right interface.

Learn that terminal text is not Omen's canonical machine truth, typed references can replace rediscovery, semantic actions are stronger when meaning matters, and AI judgement is explicit.

Omen deliberately does not grow a replacement shell programming language for complex scripting.

## Fish

Fish demonstrates the value of strong defaults, discoverability, completion and interactive friendliness.

Omen shares the instinct that a shell should be pleasant before the user spends a weekend configuring it.

The additional Omen idea is first-class machine-facing semantics/evidence.

## PowerShell

PowerShell users already know the value of structured objects over plain text.

Omen agrees with that underlying lesson but has a different scope: typed runtime truth around executions, resources, evidence, semantics and capabilities while preserving ordinary programs.

## Nushell

Nushell strongly demonstrates structured data, discoverable commands and modern shell UX.

Omen borrows the lesson without adopting Nu's language as its internal model.

Nushell remains a good real scripting language when composition requires actual programming.

## Coding agents

The biggest shift is:

> stop treating the terminal transcript as the agent's memory.

Ask Omen for current state, carry references, retrieve detail lazily, and use deterministic semantic tools before model interpretation.
