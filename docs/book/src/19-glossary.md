# 19. Glossary

## Admitted
Currently authorised for the actor. Not the same as available.

## Artifact
Immutable supporting evidence, commonly addressed through artifact://.

## Assurance
Nature/strength of support behind a claim.

## Available
Omen has a usable implementation/provider for a capability in the current environment.

## CAS
Content-Addressed Storage.

## Context generation
Version/generation representing changing live workspace/runtime truth.

## Contract digest
Deterministic fingerprint of static Machine Contract semantics.

## DIRTY
A dependency changed and revalidation is required before current proof can be claimed.

## Fact
Deterministic semantic claim whose validity depends on witnesses/generation.

## Harness Tax
Working term for avoidable token, latency, compute or attention cost introduced by the agent environment.

## Machine Contract
Versioned structured description of Omen capabilities, schemas, effects and discovery surfaces.

## Observation
Something directly observed by Omen.

## Provider
Concrete implementation supplying semantic/tool capability.

## Recipe
Advisory description of how capabilities are commonly combined. Not authority.

## Reference
Typed handle to known Omen state.

## Semantic action
Colon-prefixed operation whose meaning Omen understands.

## STALE
Information remains useful/historical but is not current.

## Tethers
Authority/policy/permission boundary.

## UNKNOWN
Omen does not possess enough evidence for a stronger claim.

## Witness
Evidence/dependency state supporting a Fact or semantic result.
