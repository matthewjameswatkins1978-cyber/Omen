# References & Attribution

Omen builds upon key concepts and mechanisms pioneered across the systems and AI engineering ecosystem. We acknowledge and give credit to the following projects:

- **Nushell**: For demonstrating that developer command streams and tool interactions should be structured tables and typed values rather than unstructured text streams.
- **ThreadMoth**: For deterministic, bounded structural mutations, strict refusal semantics, pre/post-image SHA-256 hashes, and machine-first structured JSON operations.
- **Tethers**: For the architectural separation of permission, capability identity, policy, approval, durable intent, replay, and outcome truth.
- **Resolve01**: For the clean boundary between live coordination / scope locks and physical machine execution.
- **Lantern**: For establishing the role of durable memory, context management, and provenance across sessions.
- **Dagger, Bazel & Nix**: For content-addressed storage (CAS) paradigms, input generation tracking, and reproducible execution environments.
- **Atuin & Jujutsu (jj)**: For operational logs, immutable operation sequences, and structured execution histories.
- **Cap-std**: For capability-oriented filesystem access and path safety principles.
- **Carapace & Fig**: For rich cross-shell CLI syntax specifications and completion metadata.
- **Landlock LSM**: For safe, unprivileged process sandbox containment on Linux.
- **ripgrep**: For blazing fast regex search with machine-readable `--json` streaming events.
- **cargo-nextest**: For clean test execution, structured JUnit output, and modern test orchestration.
- **ast-grep**: For structural AST search and rewrite capabilities.
